# LEAD ENGLISH — Unified Lesson Planner

The app has one unified A4 Landscape lesson-plan template for Grades 1–6.

## User flow
1. Select Grade → Semester → Unit → Lesson on the opening screen.
2. Tap **Open Lesson Plan**.
3. The lesson-plan page opens with **no Grade/Semester/Unit/Lesson menus inside the plan**.
4. Edit the paper cells if needed.
5. Print / Save as PDF.

## Important
Upload the **whole folder contents** to the repository root. The main file must be named `index.html`.
